# 🧱 Кирпич Бишкека

**Открыть сайт:** https://leraabramova77.github.io/brick-weather/

На сайте висит кирпич на верёвочке и показывает, какая погода прямо сейчас — в Бишкеке или в любом другом городе мира:

- идёт дождь — кирпич мокрый, с него капает;
- идёт снег — на кирпиче снежная шапка;
- сильный мороз — у кирпича сосульки;
- жара — кирпич раскалённый;
- ветер — кирпич раскачивается сильнее;
- ночь — луна и звёзды.

Страну и город можно выбрать вверху (сайт запомнит выбор). Кнопками внизу можно посмотреть на кирпич в любую погоду.

Погода берётся с [open-meteo.com](https://open-meteo.com) (бесплатно, без ключа) и обновляется каждые 10 минут.

Весь сайт — один файл `index.html`.
